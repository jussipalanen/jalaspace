## [0.1.0](https://github.com/jussipalanen/jalaspace/releases/tag/v0.1.0) (2026-09-22)

First public version of the JalaSpace property and space management demo.

### Added

* **app:** React, TypeScript and Vite frontend with an application shell, responsive sidebar, top header and routes for every section ([#2](https://github.com/jussipalanen/jalaspace/pull/2))
* **auth:** simulated demo sign-in with a login page, route guard, return to the requested page and sign-out ([#12](https://github.com/jussipalanen/jalaspace/pull/12))
* **data:** repository layer with localStorage persistence, the `VITE_DATA_PROVIDER` switch, and demo seed data with 4 properties, 68 spaces, 31 tenants, 62 leases and 14 maintenance tasks ([#18](https://github.com/jussipalanen/jalaspace/pull/18))
* **dashboard:** key figures, recent maintenance, available spaces and recent activity, all calculated from repository data ([#20](https://github.com/jussipalanen/jalaspace/pull/20))
* **i18n:** Finnish and English user interface with a language switcher that remembers the choice ([#24](https://github.com/jussipalanen/jalaspace/pull/24))
* **dev:** Docker development setup with `docker compose up` ([#10](https://github.com/jussipalanen/jalaspace/pull/10))
* **ci:** GitHub Actions checks (lint, typecheck, tests, build, security audit, Docker build), weekly dependency check and Dependabot ([#4](https://github.com/jussipalanen/jalaspace/pull/4))
* **tests:** Playwright end-to-end tests on desktop and mobile Chromium ([#16](https://github.com/jussipalanen/jalaspace/pull/16))

### Fixed

* **deploy:** direct links and page refreshes returned 404 on Vercel ([#8](https://github.com/jussipalanen/jalaspace/pull/8))
* **dashboard:** detail lines overflowed their panel on narrow screens ([#24](https://github.com/jussipalanen/jalaspace/pull/24))
* **a11y:** the not-found and error pages had no main heading ([#24](https://github.com/jussipalanen/jalaspace/pull/24))
